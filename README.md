# MarttDev log_ 💻🌹

> **"cada dia, uma coisa nova."** — Um diário público de desenvolvimento web para registrar a evolução constante, um aprendizado por vez.

---

## 📌 Sobre o Projeto

O **MarttDev log_** é um espaço onde documento minha jornada como desenvolvedora. O objetivo é cultivar o hábito de registrar aprendizados diários, por menores que sejam, fortalecendo a base técnica e criando um histórico real de evolução.

O projeto foi construído focando nos fundamentos do desenvolvimento web, utilizando tecnologias puras (Vanilla) para garantir performance e total controle sobre o código.

---

## ✨ Funcionalidades

- 📋 **Feed Dinâmico:** Listagem de registros carregada a partir de um arquivo JSON.
- 🔍 **Busca Inteligente:** Filtro em tempo real por títulos, texto, tags ou palavras-chave.
- 🏷️ **Categorização:** Sistema de chips para filtrar posts por tecnologias (HTML, CSS, JS, etc).
- 📱 **Design Responsivo:** Interface que se adapta perfeitamente a computadores e celulares.
- 📖 **Páginas de Leitura:** Posts detalhados com suporte a blocos de código e links úteis.

---

## 🛠️ Tecnologias

Para este projeto, priorizei a simplicidade e a eficiência:

- **HTML5:** Estrutura semântica para melhor acessibilidade e SEO.
- **CSS3:** Estilização modular com variáveis, Flexbox e CSS Grid.
- **JavaScript (ES6+):** Manipulação de DOM, Fetch API para carregar dados e lógica de busca.
- **JSON:** Utilizado como uma base de dados estática e leve.

---

## 📂 Estrutura de Pastas

```text
├── assets/          # 🖼️ Imagens, logos e favicons
├── data/            # 📦 O "banco de dados" em formato JSON
├── scripts/         # 🧠 Lógica de renderização e integração com a API
├── styles/          # 🎨 CSS modularizado (Header, Hero, Grid, Post, etc)
├── index.html       # 🏠 Página principal (Feed)
├── post.html        # 📄 Template para leitura dos registros
└── sobre.html       # 👩‍💻 Informações sobre a autora
```
